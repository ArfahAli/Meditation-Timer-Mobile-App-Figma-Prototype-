# Meditation Timer Mobile App (Figma Prototype)

This is a UI/UX design prototype for a mobile meditation timer app, created in Figma.

## Overview

- A calm, focused interface for meditation  
- Main timer screen with visual ring, presets (5/10/15 min), and controls (Start, Pause, Reset)  
- Sound selection screen with options like Ocean, Forest, Music, etc.  
- Designed for clarity, minimalism, and a peaceful user experience  

## Design Details

- Mobile-first layout  
- Soft, rounded elements  
- Clear visual hierarchy  
- Consistent styling across screens
